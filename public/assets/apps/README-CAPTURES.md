# Spécifications pour les Captures d'Écran des Applications

Ce document fournit les recommandations pour préparer les captures d'écran des applications client et partenaire de ChapeChape Residence.

## Structure des Dossiers

Les captures d'écran doivent être placées dans les dossiers suivants :

- **Application Client** : `/public/assets/apps/client/`
- **Application Partenaire** : `/public/assets/apps/partner/`

## Dimensions Recommandées

### Captures d'écran pour smartphones

- **Résolution** : 1080 × 1920 pixels (ratio 9:16)
- **Format** : PNG ou JPG
- **Qualité** : Haute résolution (minimum 72 DPI)

### Captures d'écran pour tablettes (optionnel)

- **Résolution** : 1668 × 2224 pixels (ratio 3:4)
- **Format** : PNG ou JPG
- **Qualité** : Haute résolution (minimum 72 DPI)

## Nombre de Captures Recommandé

- **Minimum** : 4-5 captures par application
- **Idéal** : 6-8 captures par application
- **Maximum** : 10 captures par application (pour éviter de surcharger la page)

## Écrans à Privilégier

### Application Client

1. **Écran d'accueil / Tableau de bord**
2. **Recherche de résidences**
3. **Visualisation détaillée d'une résidence**
4. **Processus de réservation**
5. **Profil utilisateur**
6. **Paiement / Factures** (optionnel)
7. **Messagerie avec les propriétaires** (optionnel)
8. **Gestion des avis et notes** (optionnel)

### Application Partenaire

1. **Tableau de bord du propriétaire**
2. **Gestion des propriétés**
3. **Visualisation du calendrier des réservations**
4. **Ajout/Édition d'une résidence**
5. **Gestion des tarifs**
6. **Statistiques et revenus** (optionnel)
7. **Messagerie avec les clients** (optionnel)
8. **Gestion des avis reçus** (optionnel)

## Recommandations de Style

Pour assurer une cohérence visuelle :

1. **Mode Clair/Sombre** : Privilégiez un mode cohérent pour toutes les captures (idéalement un fond clair)
2. **Contenu** : Utilisez des données de démonstration réalistes mais non sensibles
3. **Langue** : Toutes les captures doivent être en français
4. **Appareil** : Utilisez le même modèle d'appareil pour toutes les captures d'une même application
5. **Cohérence** : Assurez-vous que les couleurs, polices et éléments d'interface respectent la charte graphique de ChapeChape Residence

## Convention de Nommage

Pour faciliter l'intégration, nommez vos fichiers selon ce modèle :

- **Application Client** : `client-01-accueil.jpg`, `client-02-recherche.jpg`, etc.
- **Application Partenaire** : `partner-01-dashboard.jpg`, `partner-02-properties.jpg`, etc.

## Différenciation Visuelle

Pour bien différencier les deux applications :

1. **Application Client** :

   - Privilégiez des écrans orientés utilisateur/locataire
   - Mettez en avant la recherche et la visualisation de résidences
   - Utilisez des couleurs plus douces/accueillantes

2. **Application Partenaire** :
   - Mettez en avant les outils de gestion et les fonctionnalités administratives
   - Privilégiez les vues analytiques et les tableaux de bord
   - Utilisez des couleurs plus professionnelles/business

## Optimisation

- Compressez vos images pour optimiser le temps de chargement du site
- Visez une taille de fichier inférieure à 200 Ko par capture d'écran
- Vous pouvez utiliser des outils comme TinyPNG ou ImageOptim pour compresser sans perdre de qualité
